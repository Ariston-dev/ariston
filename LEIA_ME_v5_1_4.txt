COMO APLICAR AO REPOSITORIO EXISTENTE
1. Feche o CorelDRAW 2022.
2. Extraia este ZIP.
3. Abra o GitHub Desktop e escolha Repository > Show in Explorer.
4. Copie para a pasta do repositorio AS PASTAS .github e CorelAddon do ZIP,
   escolhendo substituir os arquivos existentes quando perguntado.
5. No GitHub Desktop confira que estes 5 arquivos aparecem novos/modificados:
   .github/workflows/compilar-plugin-windows.yml
   CorelAddon/LaserToolsFree.Docker/DockerUI.xaml
   CorelAddon/LaserToolsFree.Docker/DockerUI.xaml.cs
   CorelAddon/tests/test_white_docker_diagnostics.py
   CorelAddon/tools/Testar-Painel-WPF.ps1
6. Commit to main, depois Push origin.
7. No GitHub Actions confira 'Compilar DLL WPF no Windows' e a etapa
   'Testar carregamento real do XAML em ambiente WPF Windows'.
8. Se todos os jobs estiverem verdes, baixe o PRIMEIRO artifact montado.
9. Extraia por completo o ZIP gerado. Feche o CorelDRAW 2022.
10. Execute o instalador PowerShell apontando -CorelPrograms64 para a pasta
    existente do CorelDRAW 2022. Nao mude o destino para 2024.
11. Reabra o CorelDRAW 2022 e tente abrir a aba Laser Tools Free.
12. Se a aba continuar vazia, procure o arquivo de diagnostico:
    Documentos\LaserToolsFree\Logs\Docker_WPF.log
    Se nao houver log, a falha pode ter acontecido antes da criacao do controle.
